# Caden Otis - Personal Portfolio Website

My personal portfolio website showcasing my academic background, professional experience, skills, and projects. Built with plain HTML and CSS and hosted on GitHub Pages.

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Landing page with an about me intro, education summary, honors & awards, and contact info |
| `experience.html` | Work history at Rice Lake Weighing Systems and John Deere |
| `skills.html` | Technical skills organized into categories (languages, web tech, tools, hardware) |
| `projects.html` | Projects from coursework and personal work (portfolio, Wordle, temp sensor, processor, Roomba) |

## Tech Stack

- HTML5
- CSS3

## Running Locally

No build step or dependencies — it's plain static files. You can either:

1. Open `index.html` directly in a browser, or
2. Run a quick local server:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Deployment

The site is deployed to GitHub Pages from the `main` branch (root directory). Pushing to `main` automatically updates the live site at https://cadenrotis.github.io/Website/.
